¿Qué te pedimos que hagas?
Partiendo de la última versión de tu aplicación (JavaFX + MySQL), deberás implementar dos nuevas funcionalidades accesibles desde la interfaz gráfica:

1. Gestión de XML mediante DOM

Creación de paquetes
Debes crear los siguientes paquetes:

 biblioteca.fichero
biblioteca.utilidades
 

Clase UtilidadesXML

En el paquete utilidades, crea la clase: UtilidadesXML

Esta clase será la encargada de trabajar con documentos XML mediante DOM.

Métodos obligatorios:

Document xmlToDom(String ruta): Convierte un fichero XML en un árbol DOM.
void domToXml(Document dom, String ruta): Convierte un árbol DOM en un fichero XML.
Document crearDomVacio(String etiquetaRaiz): Crea un documento DOM vacío con la etiqueta raíz indicada.
- Copia de seguridad (exportación a XML): 

Se añadirá en la interfaz gráfica la opción:  “Hacer copia de seguridad”

Esta opción deberá:

Obtener los datos desde la base de datos (modelo actual).
Convertirlos a estructuras DOM.
Generar los siguientes ficheros XML:
usuarios.xml
libros.xml
autores.xml
prestamos.xml
 
- Restauración (importación desde XML)

Se añadirá la opción: “Cargar copia de seguridad”

Esta opción deberá:

Leer los ficheros XML.
Convertirlos a objetos del dominio.
Eliminar los datos actuales de la base de datos.
Insertar los nuevos datos desde los XML.
 Adaptación de clases de negocio:

Para cada clase que gestione colecciones (Usuarios, Libros, Autores, Prestamos), deberás añadir funcionalidad XML.
